# Claude Workspace — 공통 설정

> 이 워크스페이스는 여러 Claude Code 프로젝트를 하나의 레포에서 관리하는 모노레포입니다.

## 프로젝트 구조

```
claude-workspace/
├── .claude/
│   └── CLAUDE.md          ← 공통 설정 (이 파일)
├── 노선글작성/
├── 논문번역/
├── 통합플랫폼/
└── 풀스텍개발/             ← 풀스택 멀티 에이전트 빌더
    └── CLAUDE.md           ← 프로젝트별 상세 설정
```

## 공통 규칙

- 각 프로젝트 폴더 안에서 작업할 때 해당 프로젝트의 CLAUDE.md가 우선 적용됩니다
- 각 프로젝트 산출물은 해당 프로젝트 폴더 내 `output/` 에 저장합니다
- 원본 코드는 절대 수정하지 않으며, 모든 변경은 복사본을 대상으로 합니다

## 프로젝트별 안내

| 프로젝트 | 설명 |
|---------|------|
| 풀스텍개발 | 자연어 요구사항 → 풀스택 앱 생성·고도화 에이전트 시스템 |
| 노선글작성 | (프로젝트 CLAUDE.md 참고) |
| 논문번역 | (프로젝트 CLAUDE.md 참고) |
| 통합플랫폼 | (프로젝트 CLAUDE.md 참고) |
