# human-gate 스킬

## 목적
사용자에게 승인을 요청하고 응답을 파싱하여 워크플로우의 다음 행동을 결정한다.
비개발자를 위해 기술 용어 없는 자연어 요약을 기본으로 제공한다.

## 응답 파싱

### 승인으로 간주
- 네, 응, 좋아, 진행, 맞아, 확인, 확정, 승인
- ok, yes, proceed, confirm, good, great

### 거부/수정 요청으로 간주
- 아니요, 아니, 수정, 변경, 바꿔, 다시
- no, change, modify, update

### 수정 내용 분류 (G1 전용)
1. 사용자의 수정 요청을 분석
2. **소규모**: 단어 변경, 기능 이름 수정, 설명 추가 → 메인 에이전트가 requirements.md 직접 편집
3. **대규모**: 새 기능 추가, 사용자 유형 변경, 방향 전환 → requirements-analyst 재호출

### 모호한 응답
이해하지 못한 응답은 아래처럼 재확인:
```
죄송합니다, 정확히 이해하지 못했어요.
"네"로 진행하거나, 수정하실 내용을 구체적으로 말씀해주세요.
```
